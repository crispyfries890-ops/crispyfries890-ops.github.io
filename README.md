# Shradha Singh | Portfolio

Personal portfolio website built with plain HTML, CSS and JavaScript (no build step).

## Edit before publishing
1. `index.html`: replace `YOUR-USERNAME`, `YOUR-REPO`, `your.email@example.com` and the LinkedIn link, and swap the sample projects for your own.
2. Photo is at `assets/photo.png`. Replace it any time with another image of the same name.

## Publish on GitHub Pages
1. Create a new repository on GitHub. For a main site name it `YOUR-USERNAME.github.io`.
2. Upload all files in this folder (`index.html`, `style.css`, `script.js`, `README.md`, `assets/`).
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/`.
